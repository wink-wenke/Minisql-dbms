# DBMS 工程化开发流程

## 1. 项目总体目标

本项目基于 `java simpledb` 进行二次开发，在理解原有 DBMS 架构和执行流程的基础上，根据课程要求对系统进行功能补充、模块改造和性能优化。

核心目标：

1. 跑通原始 DBMS
2. 理解完整 SQL 执行流程
3. 阅读并分析核心源码
4. 建立课程要求与原项目功能的映射
5. 确定模块边界和接口
6. 三人并行开发
7. 完成模块测试与系统集成
8. 根据课程要求实现深化/拓展功能
9. 完成性能测试、实验数据和项目答辩材料
